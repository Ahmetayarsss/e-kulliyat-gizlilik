# e-kulliyat-gizlilik

e-Külliyat uygulamasının gizlilik politikası (`index.md`), veri silme sayfası (`veri-silme.md`) ve e-posta doğrulandıktan
sonra açılan sayfa (`dogrulandi.md`; Supabase → Authentication → URL Configuration → Site URL).
GitHub Pages ile yayımlanır; mağaza sayfalarında bu adresler verilir. Uygulamanın kodu bu depoda değildir.
